## State machine

```
enabled=false ──────────────────────────────────────────── stays 'loading'
                                                              (no load call)
enabled=true:
  enter ──► 'loading' (always, even if loadLocal resolves first)
              │
              ├─ loadLocal resolves (any data, including []) ── still 'loading'
              │   loadLocal rejects ──────────────────────────── still 'loading'
              │
              ▼
         load() settles:
              ├─ resolves ──────────────────────────────────► 'ready' (authoritative=true)
              └─ rejects:
                    ├─ offlineTolerant=true AND localOk=true ► 'ready' (authoritative=false, data=localData)
                    └─ otherwise ─────────────────────────► 'error'

reload() ────────────────────────────────────────────────► re-runs from 'loading'
dep change / unmount ────────────────────────────────────► epoch++ (stale guard)
```

Key guarantee: `status === 'ready'` is the only gate to "empty". An empty local cache (loadLocal returns []) while the authoritative load is pending keeps status at 'loading', preventing the false-negative "No X" flash.

## Concerns / notes

1. **`AlertTriangle` already existed** in `icons.ts` under the "Status & Alerts" group — no addition needed.
2. **tsconfig.json excludes `src/hooks/__tests__/`** implicitly (via `exclude: src/**/*.test.tsx`) so the hook test file is not included in the tsc build, which is correct.
3. **`use-mobile.ts` uses `window.matchMedia`** (DOM) — that pre-existing hook is web-only. The new `use-async-data.ts` has zero DOM imports (only React's `useCallback`, `useEffect`, `useRef`, `useState` and `DependencyList` type) and is safe for React Native.
4. **`async-states.tsx` is web-only** (`'use client'`) — this is intentional per the spec. RN consumers use the hook directly with their own native render logic.
5. The stale-guard test (dep change mid-flight) was included as a bonus beyond the minimum spec — it validates the epochRef mechanism that prevents flashing stale data on rapid navigation.
