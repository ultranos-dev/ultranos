Summary of Changes from v1

✓ sellingPrice moved from CatalogItem → StockBatch (per-batch pricing)
✓ CatalogItem retains defaultSellingPrice (used when no batch override)
✓ LedgerEntry promoted to own table (no embedded array bloat)
✓ PatientLedger → PatientAccount (lightweight, balance is cached/derived)
✓ GoodsReceipt added (auditable "what came in" business document)
✓ StockCount added (physical reconciliation with variance → auto-adjust)
✓ quantityQuarantined removed (status='quarantined' + qtyOnHand is sufficient)
✓ Invoice void fields added (voidedBy, voidedAt, voidReason, void_reversal movement)
✓ All amounts stored as integers (minor currency units) — no floating point
✓ CashDrawer linked to Payment via cashDrawerId
✓ StockMovement gains 'void_reversal' type for invoice voids
