timestamp: string (ISO)

// Append-only ledger — never updated, never deleted

Key Design Decisions

StockMovement is append-only — like the audit log. Every stock change is a ledger entry. quantityOnHand on StockBatch is a derived/cached value that can be rebuilt from movements.
FEFO via expiryDate index — when dispensing, query StockBatch WHERE catalogItemId = X AND status = 'active' ORDER BY expiryDate ASC. First result is the batch to deduct from.
Controlled substance balance — sum of StockMovements WHERE catalogItem.controlledSchedule IS NOT NULL, grouped by batch. Discrepancy = sum(movements) vs physical count.
Invoice ↔ Dispense link — an Invoice references one or more dispenseIds. Created automatically after dispensing confirmation. Pharmacist adds payment before printing receipt.
Offline conflict resolution — StockBatch.quantityOnHand conflicts use Tier 2 (timestamp merge). StockMovements are Tier 1 (append-only, both kept). Controlled substance discrepancies auto-flag for pharmacist review.
