New Pages (10)
Green dots = Inventory module, Yellow dots = Financial module
/inventory — Stock Overview
Searchable/filterable stock table. Columns: product, batch, qty on hand, expiry, status, zone. Alerts panel: low stock + near-expiry + quarantined. Stock value summary at top.
/inventory/receive — Receive Stock
Barcode scan or catalog search → add items with batch, expiry, qty, cost, selling price. Creates GoodsReceipt. If PO mode: select PO first, auto-fills expected items.
/inventory/catalog — Medication Catalog
Browse/search the Hub formulary cache. View product details, stock levels across batches, reorder point config. Read-only catalog; "Request Addition" button for missing items.
/inventory/suppliers — Supplier Management
CRUD supplier contacts. Links to their POs and receipts. Only visible when PO mode enabled OR when any supplier exists.
/inventory/transfers — Inter-Pharmacy Transfers
Request stock from network pharmacies, view incoming requests, ship/receive flow. Shows network stock availability. Only visible when transfers enabled.
/pos — Point of Sale
Active invoice view after dispensing. Payment collection (cash/card/credit split). Receipt generation. Links to current cash drawer session.
/pos/accounts — Patient Accounts (Credit)
Patient credit ledgers. Outstanding balances, payment history, aging report (30/60/90 day buckets). Record credit payments. Only visible when credit enabled.
/pos/cash-drawer — Cash Drawer
Open/close drawer sessions. View current session totals. End-of-day reconciliation (count cash → compare to expected → record discrepancy).
/inventory/count — Stock Counts
Start full/spot/controlled-only counts. Scan or search items, enter actual quantities. View expected vs actual, auto-generate adjustments on complete. Under Clinical group because controlled counts are compliance-driven.
/reports — Reports Dashboard
Consumption trends, fast/slow movers, wastage rate, stock valuation, daily sales summary, margin analysis, controlled substance discrepancy history, receivables aging.

Integration Points with Existing Flow

Dispensing → Stock: FulfillmentChecklist.confirmDispense() → deducts from FEFO batch → creates StockMovement('dispensed') Dispensing → POS: After dispense confirm → auto-creates Invoice(draft) → navigates to /pos for payment collection Dashboard: Adds inventory widgets: low-stock count, near-expiry count, today's revenue, open cash drawer indicator Controlled: ControlledSubstancesView now reads real schedule from CatalogItem + shows running balance from StockMovements Catalog Sync: On Hub connect → sync CatalogItem table → used by dispense flow for FEFO batch selection + pricing
