Navigation structure

expo-router file-based routing — screens are files, paths are URLs

app/ directory → screen hierarchy
app/
_layout.tsx — root: AuthGuard + font loading
(auth)/
_layout.tsx
login.tsx — OTP for patients, credentials for clinical staff
(tabs)/
_layout.tsx — 2-tab bar: Search + Profile
index.tsx — Search tab (FTS offline + API fallback)
profile.tsx — Role badge, sync status, logout
drug/
[atcCode].tsx — Drug detail (pushed from search results)
Drug detail screen — tab layout inside the screen
Overview
Clinical (Tier 2+)
Pricing
Enrich (clinical+)
Tabs are conditionally rendered based on role tier.
PATIENT sees: Overview + Pricing
DOCTOR/NURSE/LAB_TECH sees: Overview + Clinical + Pricing + Enrich
PHARMACIST/ADMIN sees: Overview + Clinical + Pricing + Enrich (with full Tier 3 fields)
Auth flow
Root _layout.tsx checks auth-store. If no token → redirect to (auth)/login. After login → redirect to (tabs). Token lives in memory only (never persisted to AsyncStorage). On app background/foreground: if token expired → re-auth screen.
