Drug detail screen (app/drug/[atcCode].tsx)
Amoxicillin  J01CA04 · Antibiotic
Overview Clinical ★ Pricing Enrich ★
★ = hidden for PATIENT role

OverviewTab: summaryPlain, usedFor, commonSideEffects, whenToSeekHelp, storageInstructions, pregnancySummaryPlain, warningsSummaryPlain — all from Tier 1

ClinicalTab: mechanismOfAction, indicationsClinical, adultDosing, pediatricDosing, renalAdjustment, adverseEvents, contraindications, interactions, pharmacokinetics — Tier 2

PricingTab: calls getPrices with device GPS; shows PharmacyPrice list sorted by distance or price. Requires network — shows offline warning if unavailable.

EnrichTab: form to set localNames (clinical+), dispensingNotes / formularyStatus / unitCost (pharmacist only). Calls enrich mutation. Optimistically updates local DB row.
