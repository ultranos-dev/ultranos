Which roles does Pharmopedia serve?

The Hub API already has a 3-tier content model — Tier 1 (public), Tier 2 (clinical), Tier 3 (pharmacist). Who is the primary audience for this app?

A

Patients only

Tier 1 content: plain-language summaries, common side effects, storage instructions, pregnancy summary. No clinical dosing, no pharmacokinetics, no pricing.

B

Clinical staff only (doctors, nurses, pharmacists)

Tier 2 + Tier 3 content: mechanism of action, dosing, adverse events, interactions, pharmacokinetics, formulary status, pricing. Designed for clinical decision support.

C

All roles — content scoped by role

Any authenticated user can use the app. Each role sees their tier: patients see Tier 1, clinical staff see Tier 2, pharmacists see Tier 3. One app, one codebase, adaptive content.

⭐ Recommended — the tier model is already built; no reason to restrict the app to one role
