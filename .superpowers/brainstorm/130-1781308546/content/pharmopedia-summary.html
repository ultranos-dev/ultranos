Complete design — Pharmopedia

Full summary before writing the spec

What we're building
A standalone Expo (React Native) app — apps/pharmopedia/ — serving as an offline-first drug reference for all authenticated roles. Content is role-tiered: patients see plain-language summaries, clinical staff see full pharmacological detail, pharmacists see formulary and pricing data.
Decisions locked
App typeStandalone Expo app
AuthAuthenticated — OTP (patient) or credentials (clinical)
RolesAll roles — tier-scoped content
OfflineFull catalog sync — expo-sqlite + FTS5
Navigationexpo-router — 2 tabs + drug detail as pushed screen
StateZustand (auth-store + sync-store)
SearchFTS5 offline (INN + brand + ATC + local names)
Brand name API fixGenerated column migration on drug_catalog in Plan 3
Features in scopeSearch, Drug detail, Pricing (online), Enrich (role-gated)
