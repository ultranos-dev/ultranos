Offline strategy

The Hub API has a drugCatalog.sync endpoint (incremental, version-based). How much of the catalog should work offline?

A

Full offline — sync entire catalog

On first launch, download the full drug catalog into local SQLite. Subsequent opens use the sync endpoint for incremental updates. Search and all detail screens work without network.

⭐ Recommended — aligns with the platform's offline-first mandate and the sync endpoint we already built

B

Partial offline — cache recently viewed only

No initial sync. Each drug detail screen caches its data on first view. Search always requires network. Lighter storage footprint.

C

Online only

Always requires network. No local database. Simplest to build, but breaks the platform's core offline-first constraint.

Not recommended — conflicts with the offline-first mandate
