Design — Section 2: Data Model

What a drug entry contains, where it comes from, and who sees what

Drug Entry Schema

Core Identity
atcCode — ATC code (canonical ID) · WHO EML
rxnormCui — RxNorm CUI join key · NLM
drugbankId — DrugBank reference · DrugBank
innName — INN / generic name · WHO / NLM
brandNames[] — trade names · OpenFDA
localNames — Dari / Pashto names · Local enrichment
therapeuticClass — ATC category · WHO
Tier 1 — Public (all logged-in users)
summaryPlain — plain-language "what is this drug" · MedlinePlus
usedFor[] — plain-language conditions treated · MedlinePlus
commonSideEffects[] — lay terms · MedlinePlus / OpenFDA
whenToSeekHelp — warning signs in plain language · MedlinePlus
storageInstructions · DailyMed
dostForm[] — tablet, syrup, injection · OpenFDA
Tier 2 — Clinical (clinicians only)
mechanismOfAction · DrugBank
indicationsClinical[] — ICD-10 mapped · DrugBank / DailyMed
contraindications[] · DrugBank / OpenFDA
adultDosing — standard adult regimen · DailyMed
pediatricDosing — weight-based · DailyMed
renalAdjustment · DrugBank
adverseEvents[] — severity-ranked · OpenFDA FAERS
pregnancyCategory · OpenFDA / DrugBank
interactions[] — severity + mechanism · DrugBank
Tier 3 — Pharmacist (pharmacists only)
All of Tier 1 + Tier 2, plus:
formularyStatus — on/off BPHS formulary · Local enrichment
facilityAvailability[] — per-facility stock signal · Pharmacy-Lite
dispensingNotes — local pharmacist notes · Local enrichment
pharmacokinetics — half-life, protein binding · DrugBank
substitutes[] — therapeutic equivalents · DrugBank / NLM
recallAlerts[] — active FDA recalls · OpenFDA
unitCost — local procurement cost · Local enrichment
Sources:
■ External APIs (DrugBank, OpenFDA, NLM)
■ Local enrichment (curated in OPD-Lite / Pharmacy-Lite)
ETL Seed Pipeline (one-time + scheduled refresh)
DrugBank API
interactions, pharmacology
+
OpenFDA API
labels, adverse events, recalls
+
NLM APIs
RxNorm, MedlinePlus, DailyMed
→
Normalizer
dedup on ATC + RxNorm CUI
→
Hub /drug-catalog
PostgreSQL drug table
