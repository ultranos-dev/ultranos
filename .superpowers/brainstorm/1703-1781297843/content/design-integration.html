Design — Section 4: Hub API Integration Touchpoints

New endpoints, how each app connects, auth/role scoping, and ETL pipeline

New Hub API Endpoints — /drug-catalog

GET
/drug-catalog/search?q=&lang=&limit=
Fuzzy search by INN name, brand name, Dari/Pashto name, or ATC code. Used by OPD-Lite (prescription entry), Pharmacy-Lite (catalog browse), and Pharmopedia (search tab). Returns name + ATC code + therapeutic class only — no tier content.
All apps
GET
/drug-catalog/:atcCode
Full drug profile. Role extracted from JWT — Hub returns only fields for that tier (public/clinician/pharmacist). Single endpoint, role-scoped response. Used by Pharmopedia drug detail screen.
Pharmopedia
GET
/drug-catalog/sync?since=&lang=
Incremental sync for Pharmopedia offline. Returns all entries updated since HLC watermark. Same pattern as existing spoke sync. Initial sync downloads full catalog; subsequent syncs are delta-only.
Pharmopedia only
PATCH
/drug-catalog/:atcCode/enrich
Local enrichment write. Only accepts enrichment fields (localNames, dispensingNotes, formularyStatus, unitCost). Never overwrites ETL-sourced fields. Clinician role → localNames only. Pharmacist role → all enrichment fields. Audit event emitted on every write.
OPD-Lite + Pharmacy-Lite
GET
/drug-catalog/:atcCode/prices?lat=&lng=&sort=distance|savings&limit=
Real-time pharmacy prices for a given drug near a coordinate. Queries pharmacy_prices table joined to facility locations. Returns pharmacy name, distance, price, stock signal. Online-only — no offline fallback. Sort by distance or savings.
Pharmopedia only
PUT
/drug-catalog/:atcCode/prices/:facilityId
Pharmacy-Lite writes/updates its retail price and stock signal for a drug. Called when pharmacist saves a price in Pharmacy-Lite. Pharmacist role only — facility scoped to their own pharmacy.
Pharmacy-Lite only

ETL Seed Pipeline

DrugBank API ⚠️ Commercial
Interactions · MOA · PK · substitutes · renal dosing
OpenFDA Free
Labels · adverse events (FAERS) · recalls · brand names · pregnancy category
NLM — RxNorm + MedlinePlus + DailyMed Free
RxNorm CUI · plain-language summaries (MedlinePlus) · structured labeling (DailyMed) · indication-specific dosing
→
Normalizer (scripts/etl/)
1. Dedup on ATC + RxNorm CUI
2. Merge fields by source priority
3. Never overwrite local enrichment
4. Flag conflicts for admin review
↓
Hub drug_catalog table
PostgreSQL · scheduled refresh monthly
Source field priority: When the same field (e.g. contraindications) exists in multiple sources, priority is: DrugBank → OpenFDA → NLM. Local enrichment is a separate column and is never in the merge conflict path.

Auth & Role Scoping

JWT Role Claim
{
  "sub": "user-uuid",
  "role": "pharmacist",
  "facilityId": "fac-uuid",
  "app": "pharmopedia"
}
Same Ultranos auth — no new token system. Role already exists on the token from existing apps.
Hub Enforcement
public / patient → Tier 1 fields only
clinician / nurse → Tier 1 + Tier 2
pharmacist → All tiers
PATCH /enrich: facility-scoped — pharmacist can only enrich drugs with their facilityId
packages/drug-db — Unchanged Boundary
✓ Stays in drug-db
• CONTRAINDICATED / ALLERGY_MATCH / WARNING logic
• Offline interaction checking (no network needed)
• Severity levels (severity.ts)
• Local offline subset for OPD-Lite / Pharmacy-Lite
✗ Moves to Hub /drug-catalog
• Drug content (names, descriptions, dosing)
• Multilingual fields (Dari/Pashto)
• Tiered clinical content
• Pharmacy prices and availability
