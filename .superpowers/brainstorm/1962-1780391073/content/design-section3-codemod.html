The Codemod Script

A Node.js script (scripts/migrate-tokens.mjs) with a deterministic replacement table. Runs on apps/admin-portal/src/**/*.{tsx,ts,css}.

Manual Updates (codemod can't handle these)

SIDEBAR.TSX Hardcoded dark-background classes
- text-white/80 → + text-sidebar-foreground/80
- text-white/60 → + text-sidebar-foreground/60
- hover:bg-white/[0.08] → + hover:bg-sidebar-accent
- bg-white/[0.12] → + bg-sidebar-accent
- border-white/10 → + border-sidebar-border
- text-accent (active) → + text-sidebar-primary
LAYOUT.TSX Font variable injection

Add Manrope + Public Sans via next/font/google. Apply .variable classes to <html>.

TESTS Snapshot updates only

Existing tests assert class names like bg-canvas. After codemod, run pnpm test and update snapshots with -u flag.

Excluded from codemod: The 6 inline SVG components listed in CLAUDE.md (token-icons, ResultColorIndicator, ConfidenceIndicator, QcHistoryView, CulturalFlagsBanner, CulturalFlagsEditor) use hardcoded hex/oklch values — these are intentional and stay unchanged.
