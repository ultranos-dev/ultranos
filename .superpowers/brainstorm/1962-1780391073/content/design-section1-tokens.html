Design — Section 1: Token Mapping

Current admin-portal tokens → ShadCN Radix Rhea names. Does this mapping look right?

Direct 1-to-1 Renames

Current class → ShadCN class
bg-canvas→bg-background
bg-surface→bg-card
bg-surface-raised→bg-popover
bg-sidebar→bg-sidebar
text-text-primary→text-foreground
text-text-secondary→text-muted-foreground
text-text-on-dark→text-primary-foreground
bg-accent / text-accent→bg-primary / text-primary
border-border→border-border
text-danger / bg-danger→text-destructive / bg-destructive

border-accent/20→border-primary/20
bg-danger-subtle→bg-destructive/10

bg-warning-subtle→bg-warning/10
bg-success-subtle→bg-success/10

Custom Extensions (not in ShadCN base)

warning and success tokens have no ShadCN equivalent.
We keep them as custom CSS vars + Tailwind extensions:

--warning: oklch(0.75 0.15 70); --success: oklch(0.72 0.17 145); /* in tailwind.config.ts: */ warning: 'oklch(var(--warning))', success: 'oklch(var(--success))',
Dark mode selector: Keep [data-theme="dark"] — no need to switch to .dark class.
Tailwind config: darkMode: ['selector', '[data-theme="dark"]']
