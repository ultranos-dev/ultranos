Radix Rhea Migration — 3 Approaches

Theme: teal-green primary · Manrope + Public Sans · 0.625rem radius · OKLCH palette
Decision: adopt ShadCN token naming convention across the codebase

A

Manual Rename

Update globals.css + tailwind.config.ts, then hand-edit each component file.

Scope: ~90 component files
Risk: Medium — easy to miss references
Reversible: Yes, via git

Pros

  • Full visual review of each change
  • No tooling needed

Cons

  • Slow, tedious
  • Risk of missed references
RECOMMENDED
B

Automated Codemod

Write a deterministic token-map, run a find/replace script across all TSX files, review via git diff.

Scope: ~90 component files (automated)
Risk: Low — deterministic mapping, diff review
Reversible: Yes, via git

Pros

  • Comprehensive, no missed refs
  • Fast — single pass
  • Clean git diff for review
  • Full ShadCN compatibility

Cons

  • Requires mapping validation
  • Some tokens need custom additions (warning, success)
C

Dual-Layer Aliases

Keep existing token names, add ShadCN aliases that point to them (e.g. --background: var(--color-canvas)).

Scope: globals.css + tailwind.config.ts only
Risk: Very low — no component changes
Reversible: Yes, trivially

Pros

  • Zero breakage risk
  • Minimal diff

Cons

  • Two parallel token systems
  • ShadCN components still need manual adaptation
  • Doesn't fully deliver on Option B decision
