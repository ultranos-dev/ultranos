Font Loading — layout.tsx

import { Manrope, Public_Sans } from 'next/font/google'

const manrope = Manrope({ subsets: ['latin'], variable: '--font-manrope' })
const publicSans = Public_Sans({ subsets: ['latin'], variable: '--font-public-sans' })

// <html> tag gets both CSS variables:
<html className={`${manrope.variable} ${publicSans.variable}`}>
Heading font usage: Add font-heading class to h1/h2 elements in components that want the Public Sans weight distinction. Not mandatory — font-sans (Manrope) is the default everywhere.
One decision here: The original sidebar was a deep dark green (--color-sidebar: oklch(0.18 0.01 150)). The Rhea theme's sidebar token is meant to be light. Should we keep the dark green sidebar (just rename the token) or switch to Rhea's native light sidebar style? Let me know.
